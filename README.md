# Self-Driving Car Simulation  

Welcome to the **Self-Driving Car Simulation**! 🚗  
Click on any square to set the car's destination, and watch as it drives itself to the desired location. When the car arrives at one of the four predefined destinations, a unique message will be displayed!  

---

## Features
- Click anywhere on the grid to set a destination for the car.  
- The car will automatically navigate to the selected square.  
- Special messages appear when the car reaches one of the following locations:
  - **FamilyMart**  
  - **Post Office**  
  - **Restaurant**  
  - **School**
